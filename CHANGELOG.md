# Changelog

## v1.1 — 2026-11-10

- **Faster play:** autosave only happens after battles that matter (a death, a catch, an area's first encounter, beating Lance or Red), instead of before and after every encounter. This removes the long pauses on Delta.
- Professor Oak's rules speech updated to match ("the game saves whenever it matters").

## v1.0 — 2026-11-10

First release.

- Core Nuzlocke rules: encounter rule, shiny clause, permadeath with GRAVEYARD box, forced nicknames, wipeout = game over, autosave / no soft reset.
- Professor Oak explains the rules in the intro.
- NUZLOCKE RUN OVER screen with final team; a finished save always reopens on it.
- Victory screens for Champion Lance and Red, saved as snapshots.
- Records screen on SELECT: current run, encounter log, victories.
- Encounter log: first encounter per area with ○ caught / × failed.
- Pokégear map Nuzlocke view (SELECT on the map).
- Test mode (hold L/R + SELECT for 5 s) that never writes to the save file.
